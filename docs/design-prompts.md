## Google Stitch

### initial prompt

A web app to capture, store, search and share travel recommendations like restaurants, bars, hotels, shopping, events, etc. The items are grouped an presented by city with the ability to sort and filter by type (e.g. hotels). The items will also be able to be displayed on a map.

It should be minimal with simple, intuitive search. A simple yet elegant image on the main page with a horizontal scrolling cards of the most recent items added to the site.

The app will include an admin page allowing admins to add new items, new cities, and new categories.
